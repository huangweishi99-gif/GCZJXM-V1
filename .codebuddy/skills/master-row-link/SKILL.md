# 母行链接标准（硬性）

## 判定规则（链接依据）

**三项全同才算同项，才可链接**：项目名称一致 **且** 项目特征一致 **且** 计量单位一致。
- 名称、特征比较前做归一化（NFKC、去空白、全半角统一）；特征里的规格差异（如厚度、品牌、型号）视为**不同项，不得链接**。
- 工程量不同不影响链接（同项不同量）；综合单价列不同不影响。
- 同 sheet 内链接；跨 sheet 同项不链接（子表各自独立组价），除非用户明确要求。
- 名称相同但特征一个写了做法一个没写 → **不得链接**（缺特征视为信息不足，标"待确认"而不是链接）。

## 标记与链接（硬性）

1. **母行 = 同组同项中工程量最大（或首次出现）的行**；该组其余行是子行。
2. **母行整行 A:Q 标黄 FFFF00**（Interior.Color=65535）；子行不标任何颜色。
3. 子行只在成本五列做引用链接，其他列一律不链接：
   - L 主材 `=$L$7`、M 损耗 `=$M$7`、N 人工 `=$N$7`、O 辅材 `=$O$7`、P 机械 `=$P$7`（7=母行行号）
   - **全绝对引用（$列$行）**，与 lj 工具一致；禁止相对引用（筛选/排序/插行后会漂移）。
   - 写入用 Excel COM 保真（见 qingdan-format-standard 技能铁律），链接写入后 K/Q/R/S 公式自动带出。
4. 子行所在行的 K（单价合计）保持公式 `=L*(1+M)+N+O+P`，自动跟随母行。

## 执行流程

1. 用 Python 读出全部数据行（名称/特征/单位/工程量），按归一化键分组。
2. 输出"同项分组报告"：组数、每组行号、母行选定、特征差异警告（名称同但特征不同 → 列为不可链接清单给用户确认）。
3. COM 打开副本：母行整行涂黄 → 子行五列写 `=$列$母行号` → Save。
4. 验证：抽 3 组链接点验公式与值；报告链接总数与未链接原因分布。

## 红线

- 宁可不链接，不可错链接（错链接 = 同项误判，污染成本）。
- 费率引用恒为 `$列$1` 绝对；费率参数行（第 4 行）不参与任何链接。
- 费项行（规费/税金/措施费类，无实体工艺）不做母行链接。
