# 人材机判断机制（目标：资料积累后 ≥80% 可自动判断）

> 不能做到 100% 准确；通过**多源融合 + 分项置信度 + 工艺校验**，在样本充足时力争 **≥80%** 的清单项可自动或半自动给出可靠的人材机拆分。

---

## 一、判断什么

对每条清单（**名称 + 项目特征 + 单位** 三者缺一不可），输出：

| 输出 | 说明 |
|------|------|
| 主材 / 辅材 / 人工 / 机械 | 元/清单单位 |
| **综合置信度** | 0~1 |
| **分项置信度** | 各列单独可信度 |
| **来源** | line_match / craft_profile / material_plus_template / … |
| **预警** | 如「涂料项人工为 0」 |
| **解释摘要** | 面向人工复核的来源、置信度、分项结构一句话说明 |
| **风险标签** | 高可信/需复核/弱匹配/仅市场参考/项目编号敏感等复核提示 |

### 组价对照原则（必守）

每条清单须 **同时** 对照以下三项，缺一则不得自动填价：

| 维度 | 作用 | 缺失后果 |
|------|------|----------|
| **项目名称** | 定做什么 | 无法匹配历史项 |
| **项目特征** | 定工序/做法/主材规格 | 禁止份额盲套、禁止平面市场参考 |
| **单位** | 定单价口径（㎡/m/套…） | 整项匹配直接排除；市场规则不匹配 |

实现：`src/pricing/line_identity.py` + `config/settings.json` → `line_identity`。

## 二、判断层次（优先级从高到低）

```text
⓪ 项目主材编号表（PT/ST/CT…）— 须按特征工序分解，禁止盲目整价
        ↓ 无编号 / 含龙骨石膏板基层 / 工序无法分解
① 整项历史匹配（名称+特征+做法标签均达标）
        ↓ 未达 80% 置信
② 工艺价型库 craft_cost_profiles（同工艺×同城×同档，样本≥3 更稳）
        ↓
③ 主材价库 + 工艺份额模板（主材准、辅材/人工按历史份额推算）
        ↓
④ 不填或弱参考（<55%），备注需人工组价
```

| 来源 | 典型置信度 | 何时自动填入 |
|------|------------|--------------|
| `paint_process` | 0.84 | 涂料清单按特征工序拆价（无编号或替代平面市场参考） |
| `ceiling_cl_paint` | 0.88 | 深海 CL 灯槽/边槽：须 **㎡ + 特征含投影**，元/㎡ 综合价 |
| `decorative_diffuser_length` | 0.90 | 装饰条形风口：规格长度×宽度档延长米价（个） |
| `project_material_code` | 0.88 | 名称/特征含项目主材编号，且工序分解成功；暗门/干挂/天棚侧面/拼花等复合工序降级复核 |
| `line_match` | 0.80~0.98 | 名称+特征+做法均相似 |
| `market_reference` | 0.78~0.82 | `config/market_reference_prices.json` 公开市场/信息价；复核参考价用明确名称/特征窄规则，含项目编号、喷白或按份额拆分时仅参考 |
| `craft_profile` | ≤0.74 | 同工艺样本≥3且非「装饰综合」、通过合理性校验 |
| `material_plus_template` | 0.68~0.78 | 有规格主材价 + 工艺模板 |
| `line_match_weak` | 0.55~0.79 | 导出时参考填入并标注 |
| `unresolved` | <0.55 | 不自动填 |

阈值：`config/settings.json` → `component_judge.auto_fill_confidence`（默认 **0.8**）。

自动填入还会经过最终复核闸门：市场参考价若非定稿口径、含项目编号、喷白口径或“市场合价按工艺份额拆分”，以及 `line_match` 置信度低于 0.8、项目编号复合工序、风口规格换算、照明代号、冷媒/软接、灯槽延米等，均保留组价结果但改为人工复核。当前先建立高可信自动填基线，再从待确认清单逐项恢复安全覆盖。

市场参考价的新增规则优先采用“明确名称 + 必要特征 + 城市但不使用 `sz_`/`zh_` 前缀”的复核口径，例如钢结构龙骨石膏板窗帘盒、防雨空调室外机配电箱、水压试验/系统调试、暗藏检修口、双头射灯、白色亚光板、摩素板、SF 软瓷/透光片、石材防护涂料、金属构件防火涂料、环氧自流平和保温卷帘门。这样可以改善分项参考质量，同时不扩大自动填入覆盖。

### 项目主材编号（PT-01 等）工序口径

`售楼处主材料.xlsx` 中 **PT-01=110 元/㎡** 是肌理无机涂料**材料采购价**，不是任意含 PT-01 字样的整项综合单价。

`src/pricing/material_process_price.py` 解析名称+特征中的工序后分摊：

| 特征形态 | 主材计入 | 人工 |
|----------|----------|------|
| 刮腻子 + 涂料一道（地库简易项） | 表价×5%（≈腻子辅材） | 按腻子遍数+涂刷 |
| 肌理/无机涂料饰面一底两面 | 表价×78%（饰面用量） | 腻子+底漆+饰面工序 |
| 含轻钢龙骨/石膏板基层 | **跳过层0**，走历史或市场整项 |

### 深海 CL 灯槽/边槽（`ceiling_cl_paint`）

定稿与招标清单均为 **㎡**，特征须写 **「按水平投影面积」**（含侧封板等），**不是**外网常见的灯槽延长米（元/m）。

| 校验项 | 要求 | 误套后果 |
|--------|------|----------|
| 单位 | 仅 `㎡` / `m2` | 单位=m 时不走本规则 |
| 名称 | `CL-01` / `CL-02` + 灯槽或边槽 | 与普通天棚涂料区分 |
| 特征 | 含「投影」 | 防止按延长米或纯饰面工序套价 |

单价为 **元/㎡** 综合价（基层+涂料打包）：灯槽约 253、边槽约 379（与定稿一致）。分项拆解按深海定稿：灯槽 `主材86.12/辅材55.72/人工106.37/机械5.07`；边槽 `主材129/辅材83.47/人工159.35/机械7.59`。

### 装饰条形风口（`decorative_diffuser_length`）

深海定稿按 **规格长度（mm）÷1000 × 延长米单价** 计「个」价，非平面 market 整价。

| 宽度档 | 延长米单价 |
|--------|------------|
| ≤160mm（常见 150 宽） | 80 元/m |
| 200 宽 | 106.5 元/m |

从特征 **型号/规格** 解析 `L×W`；解析须在原始换行文本上进行，避免 `150` 与下一行序号 `4.` 粘连成 `1504`。

### 电力电缆（`mep_install_price.lookup_power_cable_components`）

YJV/YJLV 电缆按单个规格计算导体截面：优先读取特征中的 **规格/型号规格**，否则读取电缆型号后的首个 `4*25+1*16` 片段。名称与特征同时出现同一规格时不得重复累加；`1.0KV`、清单序号等数字不得参与截面计算。当前估算法仅在历史整项置信不足时兜底，暂不作为自动填价来源。

### 桥架 / JDG / 消防配管（`mep_install_price`）

桥架按宽度估算人工：`人工 = 18 + 宽度×0.10`；JDG15/20/25/150 使用规格小表兜底；消防喷淋 DN100 以上钢管单独按消防配管口径处理。管径解析优先显式 `JDG/KBG/DN/Φ`，中文后缀如 `DN150新增` 不能用 `\b` 判断边界。

### 配线 / 电线（`mep_install_price.lookup_hvac_duct_components`）

普通 BV/BYJ 单芯按截面估算；`RVV-7*1.5`、`RYJS-2x1.5`、`RYS-B2-2X2.5` 等多芯线按 **芯数×截面** 的总截面计算，避免只取末尾 `1.5/2.5` 导致主材偏低。`ZR-BV-6` 等大截面单芯仍保持单芯口径。

### 机电附件 / 线性灯

`mep_install_price.lookup_mep_accessory_components` 处理金属软管 DN20/25、24/48 口配线架、水表 DN40、末端试水装置 DN25、闸阀/截止阀 DN20、止回阀 DN65/DN100、消防弱电模块、通风器、智能电表、七氟丙烷 70L、移位配电箱等零散安装附件，减少 generic unresolved 和弱历史误套。此类零散机电附件目前只作复核参考价，不直接自动填入。照明代号中 `Rm/Lc/Ls` 线性灯、灯带、LED硬灯条按 35/5/18 口径；`T.2 LED硬灯条` 按 22/0.5/8 单独处理。

### 不锈钢 / 古铜线条

名称或特征明确写有 **展开面 xx mm** 的不锈钢、古铜、MT 收口条优先走 `metal_trim_profile`，按展开面从同城样本插值；即使特征同时写有玻镁板/基层描述，也不再让弱整项抢价。无明确展开面时仍按参考价处理，不自动填。

### B2 户型精装定稿（`residential_finish_price`）

户型规则只在住宅上下文触发，公区/会所/地库不得套用。已吸收 B2 定稿编号/型号：`AB1287-400` 坐便器、`N2` 防水墙砖、`D3` 吊顶天棚、淋浴间玻璃隔断。此类规则放在通用户型模板前，避免粗模板覆盖定稿拆分。

**校准口径（深海）**：`calibration_match` 对风口按「产品+宽度」聚合为延长米带（`vent_band`），对比元/延长米而非每个长度规格逐行配对。低压电气开关按特征「名称」中的配电箱编号（如 `2-2ALG2`）对齐，勿用 `[^\n2]` 截断编号。

**特殊清单组价**（`special_line_price`，优先于主材表）：天棚面开孔人工 6 元/个；ST 石材护角弧形干挂综合；洗漱台 ST-03+钢架投影综合。ST-03 湿贴（嵌缝剂+胶粘剂）人工 85、辅材 39。石膏板（张）、CFC 保温、外围木板基层、内嵌卡座、设备三相四孔插座、双扇玻璃门、玻璃钢隔油池、SBS 平面防水卷材、成品软膜灯箱等明确小项优先于弱整项，仅作复核参考。历史整项不够强时，`lookup_misc_finish_fallback` 可兜底镜子、块料踢脚、SP 手绘壁画、停车位车档、货架安装、条形灯/路灯、电视硬盘道闸、柜体层板、硬木夹板门、小市政土建和纯材料小件等明确名称项；`lookup_finish_exact_components` 阻断过门石、局部瓷砖修补、石材窄窗台板、面包砖、防辐射细石混凝土、瓷砖排水明沟等落入 `material_plus_template` 误拆。这些规则按参考价处理，不直接放开自动填。

### 海德 WP-05 墙布

`WP-02~04`（表价 398）含不锈钢线条时机械约 **60.2**；**WP-05**（表价 80）同基层做法机械为 **12.5**，勿混用。

### 措施费（投影面积）

定稿 **垃圾清理及卫生清洁**、**脚手架费用** 均为 **19.8 元/㎡**（特征含「投影」）。招标清单若无对应行则无法 deliver 填价，仅 judge/`_finalize` 可判。

## 三、工艺类型识别

`config/craft_trade_rules.json` 定义装饰/机电工艺（涂料、块料、隔墙、吊顶、电缆、灯具等）。

- `classify_craft(名称, 特征, 单位)` → 工艺 id + 应有主辅材结构  
- 学习资料每增加 → `learn` / `backfill-kb` 自动重建 **工艺价型库**

---

## 四、合理性校验

按工艺检查：

- 涂料项是否有人工、主材  
- 地砖项是否有主材  
- 轻钢隔墙是否以辅材+人工为主  

结合 `material_catalog`（主材辅材判定表）做材料角色提示。

## 五、命令

```powershell
# 重建价库（含工艺价型）
python app.py backfill-kb

# 试判一条
python app.py judge "块料楼地面 600*600" --feature "1.水泥砂浆粘贴 2.10厚地砖" --unit ㎡ --city 深圳 --tier mid

# 批量回测准确率（对比历史人材机拆解，默认导出 Excel）
python app.py audit-judge
python app.py audit-judge --limit 500          # 快速抽检
python app.py audit-judge --include-self       # 含同项匹配（会高估，仅对比用）
python app.py audit-review --top 80            # 从 audit 明细导出待确认清单
```

导出：`data/exports/抽检报告_人材机判断.xlsx`（明细 / 汇总 / 按来源 / 按工艺）。

`judge` 单条输出会附带 `解释摘要`、`风险标签`，便于判断是否应直接采纳或进入人工复核；这两个字段只做展示，不改变自动填价逻辑。

`audit-review` 读取 `audit-judge` 明细，按“自动填但核心不准、低置信、仅市场参考、模板拆分需复核、项目编号敏感、包干/措施项”等风险导出 `data/exports/待确认清单_人材机判断.xlsx`，用于优先处理高风险前 20~80 行。

### 回测指标说明

| 指标 | 含义 |
|------|------|
| **auto_fill_rate** | 判断器认为置信度≥80%、可自动填入的比例 |
| **core_main_and_labor** | 主材、人工均在容忍范围内（分项±20% 或绝对±5元，合计±15%） |
| **accuracy_auto_fill_only** | 仅在「可自动填」子集上的准确率（是否真达到 80% 目标） |
| **exclude_self** | 默认排除同标准项，避免整项匹配套自己 |

容忍度可在命令行调整：`--rel-tol 0.20 --total-tol 0.15`。

招标导出已默认走 `judge_line_components`（`inplace_bidder`）。

## 六、如何提高准确率

1. **多给带成本拆解的历史 Excel**（`learn`）— 直接抬高 ①② 层命中率  
2. **特征写清做法**（几遍漆、砂浆/瓷砖胶、防水）— 做法标签不冲突  
3. **标注城市/档位** — 价型库按 `city × tier` 分桶  
4. 定期 `backfill-kb` — 聚合 `line_price_facts`、`material_price_facts`、`craft_cost_profiles`  

资料越多，①② 层占比越高，整体越接近 **80%+** 自动判断。
