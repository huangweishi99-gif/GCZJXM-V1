# 清单格式整理标准（硬性）

## 目标

把任意甲方招标清单整理成统一交付格式：**甲方左区原样保留（不改死数）+ 固定成本区七列 + 统一打印设置**。每次收到清单直接按本标准执行，不需要用户再提供样表或提醒。

## 执行流程

1. **读取与诊断**：先用 `scripts/inspect_format.py <文件>` 提取现有格式（sheet 数、表头行位置、列布局、已有无成本区），决定是"复用已有成本区"还是"追加成本区"。
2. **保真写入（铁律）**：修改任何既有 .xls/.xlsx **必须用 Excel COM**（win32com DispatchEx）——`shutil.copy2` 复制母本 → 打开副本 → 只写值/公式 → `wb.Save()` 保原格式。**禁止 xlrd/xlwt/xlutils/openpyxl 重写整个簿**（会丢公式、清空打印区域、改格式——福永 v3 事故根因）。
3. **左区保留**：甲方原有表头、列、样式、数值一律不动；若智能模板已识别画像（见项目 AGENTS.md 成本分析模板），按画像桥接，不硬改。
4. **成本区**：固定七列顺序——`单价合计、主材、损耗率、人工、辅材、机械、合价`。公式（全表统一）：
   - `单价合计 K = L*(1+M)+N+O+P`（同行自引用，可相对）
   - `合价 Q = K*F`（F=工程量列）
   - 机械列小数位保留 2 位；损耗率为小数（0.02 不是 2）
5. **母行链接、标色**：见姊妹技能 `master-row-link`，本技能只负责格式与打印。
6. **打印设置（每个 sheet 统一，硬参数见 `references/format-spec.md`）**：
   - A4、横向、调整为 1 页宽（FitToPagesWide=1，高度不限）
   - 打印标题行 `$1:$5`（表头跨页重复）
   - 打印区域 = 数据区（`$A$1:$Q$末行`，按实际列数）
   - 页边距 上/下/左 42.5、右 28.3；水平居中
   - 页脚居中：`第 &P 页，共 &N 页`；不打印网格线
7. **验证**：写完后用 `scripts/inspect_format.py` 复查打印区域/公式存在/字体一致，并向用户报告 sheet 清单与每表行数。

## 参考与脚本

- `references/format-spec.md` — 完整硬参数：列结构、列宽、字体字号、行高、边框、参数行、公式模板、汇总表结构。
- `scripts/inspect_format.py` — 提取任一格式的打印设置/字体/列宽/公式数（诊断与复查两用）。
- `scripts/apply_standard_format.py` — 对既有簿批量套用打印设置（A4 横向/标题行/页脚/边距，不动数据和样式）。

## 红线

- 不改甲方左区任何死数；不删 sheet；不改 sheet 名。
- 多 sheet 簿（按专业分表）每个 sheet 都要设置打印区域与标题行。
- 交付前必须验证公式链接可用（跨表引用如 `=拆除工程!$Q$27` 能算出数）。
