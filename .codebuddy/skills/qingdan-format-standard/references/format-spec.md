# 清单成本分析表格式硬参数（福永街道修缮项目定稿母本实测提取）

> 依据：`清单数据资料/甲方招标清单/福永街道一站式便民服务平台修缮改造工程-20261016/…汇总表-成本分析.xls`（18 sheet 定稿母本）。新项目如无特殊说明，一律套用本参数。

## 1. Sheet 结构

- 按专业分 sheet（拆除工程 / 结构加固工程 / 室内装修工程 / 外立面改造工程 / 电气工程 / 给排水工程 / 消防工程 / 通风空调工程 / 电梯工程 / 景观绿化 / 景观电气 / 室外管网 / 标识工程 / 建筑户外构造 / 消防水池工程 …），末尾一个 **报价汇总表**。
- 明细 sheet：表头区 1-4 行，数据从第 5 行起；底部 2-3 个汇总行（分部分项工程费 / 不含税建安工程造价 / 含税建安工程造价）。
- 报价汇总表：6 列（A 序号 / B 工程名称 / C 控制价 / D 成本合价 / E 差额 / F 备注），D 列用跨表公式引用各子表 Q 末行，如 `='拆除工程'!$Q$27`；尾部"合计"行 C=SUM(控制价)、D=SUM(成本)。

## 2. 列结构（明细 sheet，A:S 共 19 列）

| 列 | 内容 | 说明 |
|---|---|---|
| A | 序号 | 整数 |
| B | 项目编码 | 清单编码 |
| C | 项目名称 | |
| D | 项目特征 | 长文本、自动换行 |
| E | 计量单位 | m²/m/m³/个/项/t… |
| F | 工程量 | 数值 |
| G | 控制价单价 | 甲方给定，不动 |
| H | 控制价合价 | =G×F 或甲方给定 |
| I | 备注 | 可空；组价存疑时标"复合做法需工序拆分复核" |
| J | （空/分隔） | |
| K | 单价合计 | 公式 `=L*(1+M)+N+O+P` |
| L | 主材费 | 成本区五列（人填/链接） |
| M | 主材损耗率 | 小数，如 0.02 |
| N | 人工费 | |
| O | 辅材费 | |
| P | 机械费 | |
| Q | 合计 | 公式 `=K*F` |
| R | 单价相差 | 公式 `=K-G`（对比控制价） |
| S | 合价差 | 公式 `=Q-H` |

**第 4 行是费率参数行**：L4/N4/O4/P4 = 1.0（报价口径费率，K 列公式引用参数行时可乘 `$L$4` 等）。数据从第 5 行开始；每个"分部/章节"行（如"室外电气工程"）插在数据区中，不编号。

## 3. 字体与边框

| 区域 | 字体 | 字号 | 其他 |
|---|---|---|---|
| A1 大标题（分部分项工程量清单与计价表） | 宋体 | 14 | 加粗，行高 31 |
| A2 工程名称行 | 宋体 | 10 | 行高 21，下边框 |
| 表头行 3-4 | 宋体 | 10 | 水平垂直居中 |
| 数据区 A:K | 宋体 | 10 | 数据行行高 18.5，自动换行（名称/特征列） |
| 成本区 L:S | **黑体** | 10 | 与左区区分开 |
| 全表边框 | 细实线（LineStyle=1） | | 全周 + 内框 |

列宽（明细表）：A 5.9 / B 11.3 / C 16.3 / D 27.0 / E 5.1 / F 7.1 / G 9.0 / H 12.1 / I 9.1 / J 10.7 / K-S 10.7。
汇总表列宽：A 7.1 / B 34.0 / C-E 17.6 / F 11.6。

## 4. 打印设置（每个 sheet 统一）

| 项 | 值 |
|---|---|
| 纸张 | 9 = A4 |
| 方向 | 2 = 横向 |
| 缩放 | FitToPagesWide=1（1 页宽），高度自动（FitToPagesTall=False） |
| 打印区域 | `$A$1:$Q$末行`（汇总表 `$A$1:$F$27`） |
| 打印标题行 | `$1:$5` |
| 页边距 | 上 42.5 / 下 42.5 / 左 42.5 / 右 28.3 |
| 居中 | 水平居中=True |
| 页脚 | 居中 `第 &P 页，共 &N 页` |
| 其他 | 不打印网格线、不单色、不打印行列标题 |

## 5. 汇总行与标色

- 明细 sheet 底部汇总行："分部分项工程费" Q=SUM(明细 Q)；"不含税建安工程造价"=分部分项×(1+措施/规费系数)；"含税"=不含税×1.09。
- **母行（同名称+特征+单位的源头行）整行 A:Q 标黄 FFFF00**（详见 master-row-link 技能）。
- 分部章节行可浅灰/浅青底纹区分（非硬性）。
