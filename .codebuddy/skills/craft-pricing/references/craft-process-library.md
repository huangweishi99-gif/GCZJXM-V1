# 常用分项标准工序链（工艺知识库）

> 用途：组价时第 4 步"拆解工艺流程"先查本表，再对照项目特征找缺漏/多余。确认新工序后补录本文件。**标准工序 ≠ 特征必含**——特征少写了工序要提醒"待确认缺漏"；特征多写了要标"超出标准工艺"。

## 装饰装修

### 块料楼地面（m²）
基层清理 → 水泥砂浆找平（特征常见 20 厚 1:3）→ 刷素水泥膏/界面剂 → 铺贴块料（含切割、损耗）→ 白水泥/填缝剂擦缝 → 清理养护
- 缺漏高发：找平层厚度未写；结合层砂浆未写；块料规格未写
- 定额参考：020002-33 块料楼地面（深圳装饰 SJG75，定额口径 ≈214-218 元/m² 基期）

### 墙面喷刷涂料 / 乳胶漆（m²）
基层清理 → 局部修补/满刮腻子（几遍看特征）→ 打磨 → 封闭底漆（一遍）→ 面漆（特征写几遍刷几遍）→ 清理
- 警示：特征写"无机涂料"按乳胶漆同口径；写"真石漆系统"则是复合工艺（见下）

### 外墙真石漆系统（m²，复合）
基层处理 → 抗碱封闭底漆 → 中涂找平（质感砂浆）→ 真石漆主材喷涂（2 遍）→ 罩面清漆
- 禁止按"单一涂料价"组；缺哪层标哪层

### 吊顶天棚（m²）
弹线 → 吊杆安装 → 主/次龙骨安装 → 罩面板安装 → 嵌缝处理
- 主材=龙骨+罩面板；特征写"艺术吊顶/异形"人工上浮

### 石材墙面（干挂 m²）
基层处理 → 弹线埋件/龙骨（钢架）→ 石材挂件安装 → 石材安装 → 打胶/勾缝 → 清洁

## 拆除工程（拆除+清运起步）

### 天棚/墙面/地面拆除（m²）
保护性拆除（周边成品保护）→ 面层拆除 → 基层/龙骨拆除 → 垃圾装袋/清运（运距特征没写标待确认）
- 已入库参考：天棚龙骨饰面拆除 12+3（人工 12 + 辅材 3，market_reference demolition_ceiling）

### 整体拆除（项/系统）
整项包干价**不构成可比单价**——不进聚合不进链接，按项单独组。

## 安装

### 电力电缆敷设（m）
敷设（人工）→ 电缆主材（截面解析价，期刊覆盖全）→ 损耗 1% → 端头/附件（另列项时不含）
- 警示：按截面解析价组（如 4×95+1×50），禁止用小截面无规格分档价覆盖

### 镀锌钢管/塑料管敷设（m）
安装（人工）→ 管材主材（DN 规格解析）→ 管件含在辅材 → 试压/消毒（给排水）

## 土建/加固

### 钢筋（t）
制作（人工 0.9 工日/t 级）→ 绑扎安装（人工）→ 主材（期刊 2026 口径，禁止用 2021 高点）→ 垫铁/绑丝辅材
- 已校准口径：3900 主材 + 980 人工 + 500 辅材（深圳 2026）

### 植筋（根）
钻孔 → 清孔 → 注胶 → 植筋 → 固化
- 已校准三档：φ8-10 主材1.2+人工1.5 / φ12-16 2+2.3 / φ18-25 3.5+3.7（纯植筋，控制价含多工序另计）

### 碳纤维加固（m²，复合）
基层处理 → 底胶 → 找平胶 → 浸渍胶 → 碳布粘贴（层数看特征）→ 固化养护

## 景观

### 园路（m²，复合结构）
路基夯实 → 垫层（混凝土/碎石，厚度看特征）→ 基层 → 结合层 → 面层（花岗岩/透水砖/沥青）→ 养护
- 期刊无花岗岩石材价时面层留空标"待询价"，其余层照常组
