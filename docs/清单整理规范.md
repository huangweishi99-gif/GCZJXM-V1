# 清单整理规范（甲方原始清单 → 整理后清单）

> 基准：用户手工整理的《拆除工程-整理清单.xls》（20261016 福永街道一站式便民服务平台修缮改造工程）。
> 代码：`src/export/tender_normalize.py`，模板：`src/export/templates/tender_normalize_template.xls`。

---

## 1. 铁律

**数据是搬运，不能改。** 整理出来的清单与甲方原始清单必须完全一致：

- 项目编码、项目名称、项目特征描述、计量单位、工程量、综合单价、合价 —— 一个字符都不能变
- 措施项目费、规费、应纳税费 —— 直接取原清单表04 的数值，不做公式重算
- 变化只发生在**版式**上：行数、列含义、公式挂载、打印设置

**格式靠模板，不靠重画。** 输出方式永远是：以标准模板为副本改写数据。
禁止用 xlwt/openpyxl 从零绘制单元格 —— 那样会丢掉打印设置、行高、合并、边框。

---

## 2. 输入结构（甲方原始清单）

甲方清单是一整本「xx-xxxxx 系列」计价表，常见 sheet：

| sheet | 作用 |
|---|---|
| 表02 单项工程…汇总表 | 项目总览（本模块不取） |
| 表04 单位工程…汇总表 | **取汇总口径**：措施项目费 / 规费 / 应纳税费 / 不含税 / 含税造价 |
| 表08A 分部分项工程量清单与计价表 | **取清单项**（分部分项数据的唯一来源） |
| 表10 措施项目…汇总表 | 不取 |

### 表08A 列布局（0-based，所有sheet一致）

```
0 序号 | 1 项目编码 | 2 项目名称 | 3 项目特征描述 | 4 空
5 计量单位 | 6 工程量 | 7 综合单价 | 8 合价 | 9 材料设备暂估合价
```

### 表08A 的行类型识别

多页打印，每页开头会重复一次 5 行标题块（大标题 / 空行 / 工程名称 / 表头1 / 表头2），必须跳过。

| 行特征 | 类型 | 处理 |
|---|---|---|
| A 列以 `分部分项工程量清单` 开头 | 页标题块 | 跳 5 行 |
| C 列含 `本页小计` / `分部小计` / `合计` / `小计` | 小计行 | 跳过（**注意：分部小计写在 C 列，A 列是空的，容易误判成分部标题**） |
| A 列有值 **且** B 列有值 | 清单项 | 采集 |
| 仅 C 列有值 | 分部/子分部标题 | 采集成 `SectionRow` |
| 全空 | 空行 | 跳过 |

## 3. 输出格式（整理后清单）

单 sheet，sheet 名 = 工程简称（`project_name` 最后一个 `-` 或 `：` 之后的部分）。

### 列布局

| 列 | 内容 | 数字格式 | 字体 |
|---|---|---|---|
| A | 序号 | `@` | 宋体10 |
| B | 项目编码 | `@` | 宋体10 |
| C | 项目名称 | `$#,##0_);($#,##0)` | 宋体10 |
| D | 项目特征描述 | `$#,##0_);($#,##0)` | 宋体10 |
| E | 计量单位 | `$#,##0_);($#,##0)` | 宋体10 |
| F | 工程量 | `0.00` | 宋体10 |
| G | 综合单价 | `0.00` | 宋体10 |
| H | 合价 | `0.00` | 宋体10 |
| I | 备注 | `G/通用` | 宋体10 |
| J | （空分隔列） | | |
| K | 单价合计 | `0.00_` | **黑体10** |
| L | 主材费 | `0.00_` | **黑体10** |
| M | 主材损耗率 | `0.00%` | **黑体10** |
| N | 人工费 | `0.00_` | **黑体10** |
| O | 辅材费 | `0.00_` | **黑体10** |
| P | 机械费 | `0.00_` | **黑体10** |
| Q | 合计 | `0.00_` | **黑体10** |
| R | 单价相差 | `0.00_` | 宋体10 |
| S | 合价相差 | `0.00_` | 宋体10 |

### 列宽（1/256 字符宽单位）

```
A=5.86  B=11.29  C=16.29  D=27.0  E=5.14  F=7.14
G=9.0   H=12.14  I=9.14   J~AD=10.71
```

### 行结构

```
第1行   标题：分部分项工程量清单与计价表        宋体14加粗，合并 A1:I1
第2行   A2=工程名称:{project_name}，合并 A2:I2
        K2=成本单价组成，合并 K2:Q2；R2=价格对比，合并 R2:S2
第3行   表头第一行（合并见下）
第4行   表头第二行 + 成本区费率行
第5行起 数据区：分部标题行 / 清单项行
最后6行 汇总区
```

**表头两行的合并**（共 11 个合并单元格）：

```
A1:I1   A2:I2   K2:Q2   R2:S2
A3:A4  B3:B4  C3:C4  D3:D4  E3:E4  F3:F4  G3:I3
```

注意：**K/S 列不跨第4行**。第4行只放 G4=综合单价 H4=合价 I4=备注，以及成本区费率 `L4=1.0 N4=1.0 O4=1.0 P4=1.0`（M4、K4、Q4 留空）。

### 行高

```
标题行 31.0   表头行(R2-R4) 21.0
分部标题行 18.5   汇总行 23.0
清单项行 随项目特征描述长度自适应（~44~91）
```

## 4. 公式挂载规则

### 清单项行（写这 4 个，其余成本列留空由人工/组价填）

```
K{r} =L{r}*(1+M{r})+N{r}+O{r}+P{r}     单价合计
Q{r} =K{r}*F{r}                        合计
R{r} =K{r}-G{r}                        单价相差（成本-报价）
S{r} =Q{r}-H{r}                        合价相差
```

### 分部标题行（不带公式）

分部标题行只有名称，成本区保持黑体空表，**不挂 K/Q/R/S 公式**。

> 说明：用户手工模板里第二个分部（R18 室外拆除工程）带公式且装配列变成宋体，
> 属复制残留；首个分部（R5 室内拆除工程）才是标准 —— 全黑体、无公式。
> 本规范以首个分部为准，保证全表自洽。回归实测此处与模板的 5 处差异即源于此。

### 汇总区（固定 6 行）

| 行 | C 列标签 | H 列（报价） | Q 列（成本） | S 列 |
|---|---|---|---|---|
| +0 | 分部分项工程费 | `=SUM(H{首数据行}:H{末数据行})` | `=SUM(Q{首数据行}:Q{末数据行})` | `=Q-H` |
| +1 | 措施项目费 | 表04 固定值 | — | `=Q-H` |
| +2 | 规费 | 表04 固定值 | — | `=Q-H` |
| +3 | 不含税建安工程造价 | `=H0+H1+H2` | `=Q0+Q1+Q2` | `=Q-H` |
| +4 | 应纳税费 | 表04 固定值 | `=Q{+3}*D{+4}`，**D 列写 0.09 格式 0.00%** | `=Q-H` |
| +5 | 含税建安工程造价 | `=H{+3}+H{+4}` | `=Q{+3}+Q{+4}` | `=Q-H` |

SUM 的起点是**数据区首行**（含分部标题行，即使它为空白），与模板一致。

## 5. 打印设置（`ws.PageSetup`）

```
PrintArea    = $A$1:$I${末行}     ← 只打印甲方区，不含成本区；随行数变
PrintTitleRows = $1:$4            ← 表头每页重复
Zoom         = 94
HeaderMargin = 0
FooterMargin = 14.15
LeftMargin   = 42.5    RightMargin = 28.3
TopMargin    = 42.5    BottomMargin = 42.5
CenterHorizontally = True     CenterVertically = False
PaperSize    = 9 (A4)         Orientation = 1 (纵向)
PrintGridlines = False
```

> 注：以上数值来源专用 `python -m pip show` 读取用户手工模板实测。
> `xlrd`（1.2/2.x 均不行）读不到这些字段 —— 只有 Excel COM 能读写。

## 6. 用法

```bash
# 单份
python -m src.export.tender_normalize <原始.xls> <整理后.xls>

# 代码调用
from src.export.tender_normalize import build_tender
build_tender("甲方/xxx-原始.xls", "整理/xxx-整理清单.xls")
```

产物默认写在源文件同目录，命名 `-整理清单.xls`。

每改一次 `src/export/tender_normalize.py`，必须拿《拆除工程-原始清单.xls》重跑，
产物与用户手工的《拆除工程-整理清单.xls》对比：

| 校验项 | 期望 |
|---|---|
| 行数 / sheet 名 | 27 / 拆除工程 |
| 打印设置 | 15/15 一致 |
| 列宽 | 30/30 一致 |
| 合并单元格 | 11 个，差集为空 |
| 表头+数据行样式 | 114/114 一致 |
| 数据 | 15 条清单项 + 5 项汇总全部一致 |
| 已知差异 | 5 处（均在 R18，见 §4 分部行说明，属修正模板残留） |

**当前已验证：17/18 份清单可正常解析**（唯一失败的是汇总表，它没有分部分项清单，
失败属正确行为），清单项合价和与表04 分部分项工程费全部吻合。
