# 母行链接规则细则（对照 lj 工具语义 + 踩坑清单）

## lj 工具语义（清单数据资料/AI学习清单/lj/lj.exe）

lj 的链接模式：同名称+特征+单位匹配 → 目标行成本列引用母行单元格；引用一律 **全绝对**（`=$U$7`、`='地上装修工程'!$Q$1`、`='[母表.xls]Sheet1'!$F$128`）。仅同行自引用（如 `=P7*(1+Q7)`）可用相对。

## 归一化比较细则

| 步骤 | 规则 |
|---|---|
| 名称 | NFKC、去首尾空白、全角→半角；中英文括号统一 |
| 特征 | 同上；**数字/规格/品牌必须逐字符相等**才视为同特征；特征为空 ≠ 特征非空 |
| 单位 | 统一小写；`m2/m²/㎡` 视为同单位；`10m` 与 `m` 不同 |
| 分部前缀 | 名称前的章节名（如"一、拆除工程"）不参与比较 |

## 母行选定

- 默认同组内**工程量最大**者为母行（金额权重大，标黄更醒目）；
- 若工程量相同取行号小者；
- 用户指定时以用户指定为准。

## 标色规范

| 对象 | 范围 | 颜色 |
|---|---|---|
| 母行 | 整行 A:Q | 黄 FFFF00（Interior.Color=65535） |
| 子行 | 不标色 | — |
| 费率参数行（第4行） | 不标色、不参与链接 | — |
| 待确认行（特征不足无法判同） | 备注列标"特征不一致-未链接" | 不标色 |

## 常见错误清单（历史踩坑）

1. 用相对引用 `=L7` → 排序后漂移。**必须 `=$L$7`**。
2. 只在成本区链接却把母行整行标黄范围写成 A:A 单列 → 标色必须整行 A:Q。
3. 名称同、特征一个含品牌一个不含 → 错链接。**品牌/规格差异 = 不同项**。
4. 费项行（安全文明施工费/规费/税金）参与链接 → 禁止，费项无工艺。
5. 用 xlrd/xlwt 重写簿做链接 → 丢公式丢打印区域。**必须 COM 保真写入**。
6. 链接后忘记验证：至少抽 3 组点验公式、值、标色。

## 验证 SQL/脚本建议

链接完成后跑一遍：
- 每 sheet 抽子行 3 个：`cell.Formula` 应为 `=$L$母行` 形式，`cell.Value` 与母行一致；
- `inspect_format.py`（qingdan-format-standard 技能）复查打印区域未被破坏。
