### 常见报错排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `401 Unauthorized` | API Key 错或失效 | 重新核对 key，注意 `sk-` 前缀；不要带前后空格 |
| `404 Not Found` | 接口地址缺 `/v1` | 必须为 `http://host:port/v1` |
| `Network error` | 电脑/服务端不在同网 | 确认 `192.168.77.222` 在你内网可访问；用 `curl http://192.168.77.222:8787/v1/models -H "Authorization: Bearer sk-..."` 试 |
| 模型回答乱码 | 编码问题 | 切到 UTF-8 输出 |
| 工具调用不触发 | 任务太简单或没 `tool_choice` | 让 prompt 明确"请用工具查一下…" |

## 二、项目侧 AI 询价接入

> 让 `cost-estimation` 的兜底询价（`ai_price_inquiry`）真正能调 grok-4.7，而不是返回 0.25~0.4 conf 的规则估算。

### 文件清单

| 文件 | 作用 | git 跟踪？ |
|------|------|-----------|
| `config/ai_model.json` | 模型参数（base_url / model_name / enable_tool_calls） | ✅ |
| `.env` | **真实 API Key**（`GROK_API_KEY` 等） | ❌ gitignore |
| `.env.example` | 模板（给别人复制） | ✅ |
| `src/config/ai_model.py` | 配置加载（合并 ai_model.json + .env） | ✅ |
| `src/pricing/ai_price_inquiry.py` | 实现 `_query_llm` 真正调 API | ✅ |
| `src/pricing/price_inquiry_agent.py` | 实现 `_get_api_config` 走自定义 LLM | ✅ |
| `app.py::chat-test` | 验证命令（连通/对话/工具调用） | ✅ |

### 工作机制

```
external-price / audit 兜底
   └─→ PriceInquiryAgent.inquire()
         ├─→ 缓存命中：返
         └─→ _call_price_api()  ← 走自定义 LLM
               └─→ AIPriceInquirer._query_llm()
                     ├─ 读 config/ai_model.json + .env
                     ├─ POST {base_url}/chat/completions
                     │   body = {model, messages, max_tokens, temperature}
                     ├─ 解析 JSON {material_main, material_aux, labor, machinery}
                     └─→ AIInquiryResult(confidence=0.65, source=llm:grok-4.7)
```

LLM 询价 conf = **0.65**（高于规则兜底 0.25~0.4，但低于真实样本 0.95+），所以 audit 抽样里 llm 行不会"假阳性 OK"，但会替代规则估算。

### 切换模型

改 `.env`（无需改代码）：

```env

# 切到代码专用

# 切到不同端点（VPN 内网）

```

也可改 `config/ai_model.json` 永久切换；`.env` 优先级高于 `ai_model.json`（env 覆盖）。

## 三、价格与限流

- 模型按 token 计费（来自 `/v1/models` 元数据）：

| 模型 | input $/Mtok | output $/Mtok |
|------|-------------|---------------|
| grok-4.7 | 20 | 60 |
| grok-4.6 | 20 | 60 |
| grok-4.5 | 20 | 60 |
| grok-4.20-non-reasoning | 12.5 | 25 |
| grok-build-0.1（代码） | 10 | 20 |

- 长上下文（>200K）单价翻倍，本项目 max_tokens 锁 4000 足够。
- 询价结果缓存 30 天（`expires_at = now + 86400*30`），避免重复打 API。

## 四、常见操作速查

| 想做的事 | 怎么做 |
|----------|--------|
| 看现在配的什么模型 | `python app.py chat-test`（仅看配置不调对话可加 `--no-list --no-tool`，或直接看 `config/ai_model.json`） |
| 改 API Key | 编辑 `.env` 里的 `GROK_API_KEY=` |
| 换 endpoint | 编辑 `.env` 里的 `GROK_BASE_URL=`（必须含 `/v1`） |
| 调高 max_tokens | 编辑 `.env` 里的 `GROK_MAX_TOKENS=`（默认 4000） |
| 关闭工具调用 | `config/ai_model.json` 里 `enable_tool_calls: false` |
| 完全禁用 AI 询价 | `config/ai_model.json` 里改 `provider: disabled`，或 `.env` 删 `GROK_API_KEY` |
